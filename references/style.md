Rise Style Identity
Reno Rise content is structured to be:

clear

confident

simple

persuasive

human

rhythmic

easy to read

easy to trust

The style is built for homeowners — not contractors.
It removes confusion, reduces fear, and guides people toward clarity and action.

1. Core Style Philosophy
1.1. Clarity First
Every section must answer one question clearly before moving to the next.

1.2. Straight Line Movement
Content moves the reader from:

Problem → Understanding → Solution → Confidence → Action

No tangents.
No fluff.
No wandering.

1.3. Short + Long Sentence Rhythm
Use a mix of:

short punchy sentences (certainty)

longer rhythmic sentences (warmth, charisma)

This creates flow and keeps attention.

1.4. Visual Scannability
Every page must be scannable:

short paragraphs

clear headers

bold key phrases

structured sections

1.5. Emotional Anchoring
Every section must make the homeowner feel:

safe

smart

supported

ready

2. Structural Templates
These templates teach the AI how to structure content, not just how to write sentences.

2.1. Service Page Template
Code
1. Clear, confident opening
2. Normalize the problem
3. Explain the cause simply
4. Explain the solution simply
5. Future‑pace the result
6. Add light humour (optional)
7. Add trust anchors (experience, process, guarantees)
8. Add CTA
Example Opening:
Your home deserves work done right the first time. Here’s exactly what’s happening — and how we fix it.

2.2. Location Page Template
Code
1. Acknowledge local homeowner reality
2. Identify common local issues
3. Normalize them
4. Explain how Reno Rise handles them
5. Future‑pace the improved home
6. Add light humour
7. Add CTA
Example Opening:
Pickering homes deal with the same issues every year — shifting foundations, aging basements, tired decks. The good news? These problems are predictable and fixable.

2.3. Blog Post Template
Code
1. Hook (truth, humour, or insight)
2. Identify the problem
3. Break it down simply
4. Add humour or story
5. Explain the fix
6. Add value (tips, insights, warnings)
7. Future‑pace
8. CTA
Example Hook:
Your basement isn’t “mysterious.” It’s just dramatic — and it’s trying to tell you something.

2.4. CTA Template
Code
1. Simple action
2. Simple benefit
3. Emotional payoff
Example:
Fix it now. Feel better today.
Your home will thank you — and so will your future self.

2.5. Social Content Template
Code
1. Humour or truth hook
2. Quick insight
3. Quick solution
4. CTA
Example Hook:
Your deck isn’t wobbling because it’s quirky — it’s wobbling because it’s tired of holding family gatherings without support.

2.6. Email Template
Code
1. Warm opening
2. Clear purpose
3. Simple explanation
4. Benefit
5. CTA
6. Friendly close
3. Paragraph Templates
These templates teach the AI how to write individual paragraphs.

3.1. Clarity Paragraph
Code
1. State the truth
2. Explain it simply
3. Remove fear
4. Provide next step
Example:
This issue is completely normal. Here’s what’s happening and here’s how we fix it. Once it’s done, your home will feel solid again.

3.2. Reassurance Paragraph
Code
1. Validate concern
2. Normalize it
3. Provide clarity
4. Provide solution
Example:
It’s understandable to feel stressed about this. Most homeowners deal with it at some point. The good news is it’s a simple fix — here’s what we’ll do.

3.3. Humour Paragraph
Code
1. Identify behaviour
2. Exaggerate it
3. Reveal insight
4. End with hope
Example:
Your basement didn’t “just start” smelling weird. It’s been filing complaints for months. Luckily, basements are dramatic but fixable — and we handle this every day.

3.4. Future‑Pacing Paragraph
Code
1. Describe the finished result
2. Describe the emotional payoff
3. Describe the practical payoff
Example:
Imagine walking into your finished space — clean, solid, and brand new. No stress. No surprises. Just peace of mind and a home that feels right again.

5. Style Rules
5.1. Sentence Rules
Short sentences create certainty.

Long sentences create warmth.

Mix both.

Avoid passive voice.

Avoid corporate jargon.

Avoid filler.

5.2. Formatting Rules
Short paragraphs

Clear headers

Bold key phrases

Lists when helpful

No walls of text

5.3. Tone Rules
Confident

Calm

Human

Warm

Persuasive

Hopeful

6. Style Do/Don’t List
DO
Use short paragraphs

Use clear headers

Use rhythm

Use sensory language

Use future‑pacing

Use reframing

Use humour sparingly in service pages

Use humour more in blogs/social

DON’T
Ramble

Over-explain

Use jargon

Sound corporate

Sound unsure

Use passive voice

Dump information without structure

7. Example Styled Sections
Example Service Page Section
What’s Happening
Your tiles are lifting because moisture has been sitting underneath them for too long. Totally normal — especially in older homes.

Why It Matters
Left alone, this spreads. And once it spreads, repairs get more expensive. Fixing it now keeps your home solid and saves you money.

How We Fix It
We remove the affected tiles, dry the area, treat the base, and reinstall everything with stronger bonding. Clean, simple, reliable.

What You Get
A floor that feels solid again — and peace of mind knowing the problem is gone for good.

8. Final Instruction for AI
When writing in the Reno Rise style:

Follow the structural templates

Use short paragraphs and clear headers

Mix short and long sentences

Keep content scannable

Guide the reader down a straight line

Blend clarity, persuasion, and warmth

Use humour only when appropriate

Always end with confidence and hope

This is the Reno Rise style system.
