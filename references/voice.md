2. Voice Pattern Templates
These templates teach the AI how to structure Reno Rise paragraphs.

Template: Reno Rise Paragraph
Code
1. Acknowledge the homeowner’s reality
2. Normalize the problem
3. Explain the solution simply
4. Future‑pace the result
5. Close with confidence
Example:
“You’ve noticed the issue — totally normal. Here’s what’s happening and here’s how we fix it. Once it’s done, your home will feel solid again.”

Template: Reassurance Loop
Code
1. Validate their concern
2. Remove fear
3. Provide clarity
4. Provide next step
Example:
“It’s understandable to feel stressed about this. The good news is it’s a simple fix. Here’s what we’ll do next.”

Template: Straight Line Movement
Code
1. Start with clarity
2. Add context
3. Add solution
4. Add action

4. Persuasion & Reframing Examples
Objection: “It’s just cosmetic.”
Reframe:
“Cosmetic is your home’s way of whispering before it starts shouting.”

Objection: “I’ll deal with it later.”
Reframe:
“Later usually costs more — now is the smart window.”

Objection: “I don’t know where to start.”
Reframe:
“That’s our job — we make the process simple.”
